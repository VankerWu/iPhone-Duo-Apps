# iPhone Duo Apps

专注于 iPhone Duo 的第三方应用适配查询平台。

帮助用户了解不同 App 在 iPhone Duo 折叠屏上的兼容情况、界面适配表现及使用体验。

🌐 **在线访问**

https://vankerwu.github.io/iPhone-Duo-Apps/

## 网站功能

- 应用搜索与分类筛选
- 查看应用适配状态
- 查看相关适配证据与来源
- 收集用户的兼容性反馈
- 持续更新应用信息

## 适配状态说明

- **已确认适配**：有明确的适配证据
- **部分适配**：部分界面或功能仍存在兼容问题
- **待验证**：尚无充分证据确认适配情况

## 参与反馈

如果发现某款 App 已适配 iPhone Duo，或遇到黑边、界面错位、折叠交互异常等问题，欢迎通过 GitHub Issues 反馈。
